# Auth 기능 명세

## 목적

사용자가 안전하게 자신의 기록을 저장하고 여러 기기에서 접근 가능하게 한다.

---

# 로그인 방식

## MVP

- 카카오 로그인

## 추후 추가 가능

- 이메일 로그인
- 구글 로그인

---

# 기술 스택

- Supabase Auth
- Kakao OAuth

---

# 사용자 흐름

1. 로그인 페이지 진입
2. 카카오 로그인 클릭
3. OAuth 인증
4. 사용자 생성 또는 조회
5. 세션 발급
6. 온보딩 여부 확인
7. 이동 처리

---

# 페이지

### 구성

- 로고
